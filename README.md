# Flappy Bird Clone

A simple Flappy Bird-style game built with Python and Pygame.

## Description

This project is a beginner-friendly Flappy Bird clone where the player controls a bird and avoids moving pipes. The game includes gravity-based movement, collision detection, scoring, and a restart system.

## Features

- Gravity-based bird movement
- Moving pipe obstacles
- Collision detection
- Score tracking
- Game over screen
- Restart option

## Controls

- Press **SPACE** to flap
- Press **R** to restart after game over
- Close the window to quit
